# Карта на двоих

Учёт снятий с общей карты: сколько снял, что уже вернул, сколько остался должен.
Одна статическая страница, без сервера и без регистрации.

## Как выложить на GitHub Pages

1. Создай репозиторий на github.com, например `karta`.
2. Загрузи в него файлы из этой папки: `index.html`, `manifest.webmanifest`, `icon.svg`, `README.md`.
   Кнопка **Add file → Upload files** на странице репозитория, файлы можно перетащить мышкой.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment**: Source — `Deploy from a branch`, Branch — `main`, папка — `/ (root)`. Нажми **Save**.
5. Через минуту-две страница будет доступна по адресу `https://<логин>.github.io/karta/`.

## На телефоне

Открой адрес и добавь на домашний экран:

- **iPhone, Safari**: «Поделиться» → «На экран Домой»
- **Android, Chrome**: меню → «Добавить на главный экран»

Откроется как обычное приложение, без адресной строки.

## Где лежат данные

В памяти браузера того устройства, где ты их вписал (`localStorage`). На сервер не уходят,
в репозитории их нет, в истории коммитов тоже. Поэтому репозиторий можно держать публичным.

Из этого следуют два правила:

- на другом телефоне будет пустой список — данные не синхронизируются сами;
- если очистить данные сайтов в браузере, записи пропадут.

Поэтому в настройках есть **«Сохранить копию»** — выгружает всё в файл `karta-ГГГГ-ММ-ДД.json`,
и **«Загрузить копию»** — подтягивает файл обратно. При загрузке записи с одинаковыми номерами
не дублируются, так что файлом удобно переносить данные между телефоном и компьютером.

## Как обновлять

Правишь `index.html` в репозитории — GitHub Pages сам пересобирает страницу за минуту.
Записи при обновлении не теряются: они лежат в браузере отдельно от кода.
